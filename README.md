# Manchester United Next Games Chrome Extension

## Description

This Chrome extension displays the next three upcoming games for Manchester United. When you click the extension icon in your Chrome toolbar, a small toaster-style message will appear showing the fixture details.

## Features

*   Displays the next 3 upcoming Manchester United fixtures.
*   Shows opponent, competition, date, and time for each game.
*   Visually pleasing "toaster" message interface.
*   Auto-dismisses after 15 seconds.
*   Easy access by clicking the extension icon.

## Data Source

Fixture data is sourced from [TheSportsDB.com](https://www.thesportsdb.com/) API (free tier).

## Installation and Usage

1.  **Clone or Download:**
    *   Clone this repository to your local machine:
        ```bash
        git clone https://github.com/your-username/manutd-fixtures-extension
        ```
    *   Alternatively, download the ZIP of this repository and extract it.

2.  **Load the Extension in Chrome:**
    *   Open Google Chrome.
    *   Navigate to `chrome://extensions`.
    *   Enable "Developer mode" using the toggle switch (usually in the top right corner).
    *   Click the "Load unpacked" button (usually in the top left corner).
    *   Select the directory where you cloned or extracted the extension files.

3.  **Using the Extension:**
    *   Once loaded, you should see the Manchester United crest icon (placeholder for now) in your Chrome extensions bar.
    *   Click the icon to see the next three games. The popup will automatically disappear after a few seconds.
